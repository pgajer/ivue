Explore your coordinates.

Interactive point clouds, annotated graphs, surfaces, and recorded coordinate animations in R. Rotate a view, reuse a color scale, and share the result as HTML.

Install the development build

This is ivue @@VERSION@@ from the development branch, not a CRAN release. The source archive includes all five rendered guides. Install the dependencies first, then the built package:

install.packages(c("htmlwidgets", "htmltools", "rgl"))
install.packages("https://pgajer.github.io/ivue/@@ARCHIVE@@",
                 repos = NULL, type = "source")
vignette("function-guide", package = "ivue")

Download the built source package. Reading installed guides needs neither knitr nor Pandoc. Rendering a new plot requires rgl; color mapping and graph preparation work without it.

A first view

library(ivue)
X <- rbind(a = c(0, 0, 0), b = c(1, 1, 1), c = c(2, 0, 0))
height <- c(c = 0, a = 0, b = 1)
view <- plot3D.cont(X, height, legend.title = "Height")
view

Named annotations match observation IDs. Printing displays the widget in RStudio's Viewer or a browser; assigning it does not open a window. See package help for the installed starting point.
